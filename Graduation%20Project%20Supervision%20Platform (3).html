بنية الإطلاق المعتمدة — Google Workspace
تعمل المنصة كتطبيق ويب عبر Google Apps Script، مع Google Sheets كقاعدة بيانات وGoogle Drive لحفظ ملفات الطلاب وإصداراتهم، وربط OpenAI API من خلال مفتاح محفوظ بأمان في Script Properties. الخطوة التالية بعد الاختبار التشغيلي هي تفعيل الصلاحيات المنفصلة للمشرف والطلاب.

كود Apps Script الجاهز للنسخ
انسخ الكود إلى ملف Code.gs بعد كود الإعداد الأساسي. شغّل دالة initializeWorkspace مرة واحدة ثم امنح الصلاحيات المطلوبة.

يحوّل البيانات التجريبية إلى بيانات فعلية تُقرأ من Sheets وتُحفظ عند تعديل الطالب أو التقدم أو الملاحظات أو المواعيد.

ربط الذكاء الاصطناعي الفعلي
تم التحقق من الاتصال بـ OpenAI API بنجاح عبر Apps Script، وتمت تهيئة الواجهة لاستخراج النص من آخر ملف مرفوع ثم تمريره إلى reviewSubmissionWithAI لتطبيق Rubric جامعة السودان وإرجاع درجة، نقاط قوة، ملاحظات جوهرية وثانوية، مقترحات تحسين وأمثلة نموذجية وتغذية راجعة جاهزة للمشرف.
يمكن اختيار ملف المشروع أو الفصل. بعد رفع Word/PDF إلى Google Drive تبدأ المنصة تلقائيًا باستخراج النص ثم تقييمه بالذكاء الاصطناعي وفق دليل الجامعة، مع إبقاء الأزرار أدناه للاستخدام اليدوي عند الحاجة.
